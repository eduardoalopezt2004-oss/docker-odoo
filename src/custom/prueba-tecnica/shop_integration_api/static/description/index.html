API de productos para la tienda en línea

GET /api/v1/products: catálogo de productos activos y vendibles en JSON, con sesión de usuario.

  • Devuelve id, referencia, nombre, precio y cantidad libre de cada variante.
  • Filtros opcionales y combinables: categoría (con subcategorías), solo con stock y modificados desde una fecha.
  • Errores en JSON con código, campo y mensaje. Un dato mal escrito responde 400, nunca 500.

El contrato completo, con ejemplos y códigos HTTP, está en el README.md del módulo.

Solicitudes de pago

Solicitudes de pago a proveedores con flujo de aprobación.

  • Número SP/año/0001, proveedor, solicitante, monto, moneda, fecha y concepto. El chatter guarda cada cambio de estado.
  • Estados: borrador, enviada, aprobada, pagada o rechazada. Una solicitud enviada ya no se puede modificar.
  • Grupos: Solicitante (todo usuario interno, ve solo sus solicitudes), Aprobador (aprueba o rechaza, pero no lo suyo) y Tesorería (marca como pagadas).
